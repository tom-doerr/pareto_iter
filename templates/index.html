How the iteration loop works
  1. Set Max improvement iterations higher than 1 to request multiple refinement passes (1 still yields a single improvement).
  2. When you press Evaluate Pareto Loop, the app scores the current candidates, synthesizes a new proposal, scores it, and repeats until the iteration cap or stall limit is hit.
  3. The Stall limit stops the loop early if successive improvements fail to beat the best aggregate score.
  4. The results panel shows every generated proposal with badges so you can track which iterations helped.
